## 🚀 Quick Start

To launch the **Meo Mix®** web application:

```bash
# Navigate to the web UI directory
cd Meo_Mix_UI

# Install dependencies
npm install

# Start local dev server
npm run dev
```

For complete technical documentation, architectural details, and production build instructions, please refer to the [Meo_Mix_UI README](Meo_Mix_UI/README.md).
